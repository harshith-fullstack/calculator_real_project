# Python Calculator 🧮

A simple calculator project built using Python.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division by zero handling
* Exit option
* Repeated calculations using a `while` loop

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

```bash
python calculator.py
```

## How It Works

The calculator displays a menu and asks the user to select an operation.

```text
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit
```

The user can perform calculations repeatedly until the **Exit** option is selected.

## Concepts Used

* `input()`
* `print()`
* Variables
* `if`, `elif`, `else`
* `while` loop
* `break`
* Arithmetic operators
* Basic error handling for division by zero
